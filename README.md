# Task 10 – Routing Implementation in React

A clean, modern Single Page Application (SPA) built using **React** and **React Router DOM** that demonstrates client-side routing, active link styling, and modular component design.

## 🚀 Features
* **Modular Codebase:** Organized into structured files (`App.jsx`, `Task10.jsx`, and `Task10.css`).
* **5 Distinct Pages:** Fully functional routes for *Home*, *About*, *Services*, *Contact*, and *Profile* with unique, meaningful content.
* **Dynamic Active Highlighting:** Uses `NavLink` to visually highlight the selected menu block dynamically.
* **Modern UI layout:** Styled with a dark navigation header, distinct page container layout cards, and fluid spacing.
* **Error-Free Compilation:** Clean architecture running efficiently on the Vite build tool.

## 🛠️ Built With
* [React.js](https://react.dev/)
* [React Router DOM](https://reactrouter.com/)
* Custom Vanilla CSS3
